# Programmable v4 Builder v0.11.2

This patch binds Applicant writes to the protected Submit contract and adds a fail-closed Universal Admission V1 queue
preflight without enabling a queue or granting new authority.

## Protected Submit contract binding

- Applicant Draft planning and mutation now carry one exact protected Submit base plus the policy and active-contract
  observations used to derive the fresh confirmation digest.
- The transport rejects destination, source, base, head, policy and contract drift before any GitHub write.
- Public source recovery remains read-only until the Applicant supplies the existing exact confirmation required by
  the protected Draft path.

## Universal Admission queue preflight

- The Builder resolves the immutable Universal Admission V1 contract from Submit a Launch `v1.8.0` at commit
  `5a150612203b836e62cbc954a3fdef30e30546ca` and tree
  `193a6d15f830c2ca24213ab1283c2bec3fc22510`.
- It requires `.programmable/universal-admission-contract.v1.json` to hash to
  `sha256:6e7a274a2d4a14376937ab49a7d1462cb2456035139dbcd8417b59226967ce32` and verifies the repository, release, Git
  objects, contract fields and declared digest before returning a queue handoff.
- The contract remains `reference-only-disabled`. Endpoint, audience and trust snapshot are unset, every authority flag
  is `false`, and the Builder performs no enqueue, delivery, retry or dead-letter operation.

## Authority boundary

The patch can create or update only an unreviewed Applicant Draft through the existing explicit-confirmation path. A
validated queue contract is discovery metadata, not a live service. Neither result evaluates, accepts, approves,
audits, deploys, registers, makes available, routes, signs, moves funds, establishes safety or launches a project.

The bundled `publicationStateVerified: false` status is not proof that Hookbuilder `v0.11.2` is public. Protected CI,
the immutable tag and release assets, public API visibility, fresh installation and real Draft-only journeys remain
separate evidence after publication.
