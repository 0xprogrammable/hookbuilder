# Programmable v4 Builder v0.10.3

This patch repairs exact public-source resolution for large manifest-based Applicant packages without changing their
source, Application V3.1 package, review state, or authority.

## Exact-object resolver fix

- The resolver derives unique blob object IDs only from regular files in the exact REST-verified commit and root tree.
- It requests those IDs through one bounded anonymous `git fetch --stdin` batch before raw `git cat-file` size and byte
  verification.
- The previous `git backfill --sparse` step and capability probe are removed because Git could return success without
  materializing every declared object.
- Checkout, submodules, hooks, candidate execution, credentials, user Git configuration, redirects, lazy reads, and
  unbounded output remain disabled.

## Regression proof

- The focused resolver suite requires one exact-object batch, checks its complete object-ID set, preserves process and
  temporary-storage bounds, and verifies that upstream failures cannot expose Git stderr.
- Against Submit a Launch PR #36, the resolver read all 18 exact Lucky Hook records at commit
  `e4e686e223a33b4291e4e1834fe23f910c933609` and tree
  `815dc0f647e75fd8dd682f44de797e8a7e864bf9`, including the formerly missing blob
  `262dadd2d3cdccb6534c98bc5d9a36c67a5d0bfa`.

## Authority boundary

This is a canonical Builder resolver repair. It does not by itself change the protected Submit a Launch validator.
Public intake remains independently gated until that repository vendors the same reviewed resolver bytes, passes its
protected workflow, publishes its own release, and reruns the unchanged Applicant Draft.

The result grants no review, acceptance, approval, deployment, availability, signing, routing, fund-handling, or launch
authority. The bundled `publicationStateVerified: false` status is not proof that Hookbuilder `v0.10.3` is public.
Protected CI, the immutable tag and release assets, attestations, public API visibility, and a fresh installation must
be verified independently after publication.
