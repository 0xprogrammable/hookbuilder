# Programmable v4 Builder v0.10.1

This patch removes an Applicant admission deadlock while preserving the independent completion, review, approval,
deployment, and launch boundaries.

## Applicant Draft fix

- A complete project with exact public GitHub source, a valid Submission V2 package, and a valid closed Application
  V3.1 package may use the namespaced protected Draft transport without first producing `PROJECT_PREFLIGHT_VALID`.
- Authenticated external-sandbox completion remains optional stronger evidence. It is not a prerequisite for an
  unreviewed Applicant Draft and it still grants no review, approval, deployment, or launch authority.
- Local or applicant-supplied test evidence is preserved as unverified until independent review. The Builder must not
  fabricate a sandbox receipt or relabel local execution as trusted completion.

## Regression proof

- The official Skill, public Applicant guide, Application V3 reference, architecture guide, and knowledge router all
  state the same admission boundary.
- A focused transport regression proves that a generic no-Fee Application V3.1 package containing neither
  `PROJECT_PREFLIGHT_VALID` nor a `project-external-sandbox-receipt` still produces the existing protected read-only
  Draft plan with no mutating GitHub request.
- The central Application V3.1 schema, Submit a Launch target, confirmation digest, and protected review workflow are
  unchanged by this patch.

## Authority boundary

Only the exact confirmed namespaced submit or update plan may create or advance the authenticated builder's fork
branch and one Draft pull request to `0xprogrammable/submit-launch:main`. The Builder never marks the request ready,
approves it, merges it, deploys a project, signs a transaction, or grants launch authority.

The bundled `publicationStateVerified: false` status is not proof that Hookbuilder `v0.10.1` is public. Protected CI,
the immutable tag and release assets, attestations, public API visibility, and a fresh installation must be verified
independently after publication.
