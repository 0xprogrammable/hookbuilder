## Short replies

**Can it build any idea?** It keeps unfamiliar ideas eligible, but unsafe behavior or missing evidence still blocks
approval. Novel designs go to architecture review instead of being rejected by a category filter.

**Does the agent launch automatically?** No. Building, applying, approval, deployment, and public availability remain
separate stages.

**Does a green check mean audited?** No. It proves only the exact check that ran. Independent review and launch evidence
remain separate.

**Where do applications go?** New v0.5 applications go to the public Programmable Registry. Complete project source
stays in the builder's own public GitHub repository.

**What is the fee rule?** Each declared Programmable-canonical Fee V2 scope owes an inclusive 10 bps of executed gross
quote volume. An exact zero-scope project is N/A and creates no fake fee instance. The immutable fee owner and separate
platform admin cannot replace or inherit each other's authority.
