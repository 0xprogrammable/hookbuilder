# Pure service and indexer with no launch market

I want a Python indexer, a small Go alert worker, and a TypeScript dashboard that read public chain events and notify
users about unusual liquidity changes. This project creates no token, pool, hook, swap path, pricing contract, custody,
or launchable market. It never signs or submits transactions. I still want to apply to Programmable so the service can
be listed next to projects that use it. Please preserve this exact scope and prepare the design without inventing
Solidity, a fake pool, or an unnecessary fee-bearing component.
