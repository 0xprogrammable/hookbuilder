# A token tied to a living scientific game

Players grow digital ecosystems in a browser game. Public satellite tiles, player-submitted field observations and a
seasonal simulation change species traits, crafting recipes and a bounded token reward budget. Some evidence arrives
hours late and can be challenged. The game server, data adapters, hook and token contracts live in separate repositories.
There is no existing starter that matches the whole design. I want to apply without cutting the idea down to a normal
coin or pretending every component is already integrated.
