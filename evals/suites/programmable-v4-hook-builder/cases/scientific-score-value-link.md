# A research score changes token rewards

Citizen scientists upload microscope images and sensor traces. Three independent labs run versioned models and publish
signed scores for each sample. The median score changes the token reward minted for that sample and later adjusts a
monthly reward-pool multiplier. Scores can be corrected when a sample was contaminated or a model is retracted. The
project is experimental and does not claim medical validity. Can the score influence value in a Programmable custom
project, and how should this be built?
