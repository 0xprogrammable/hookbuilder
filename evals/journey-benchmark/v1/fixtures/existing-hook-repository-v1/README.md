# Legacy directional fee hook fixture

This deterministic benchmark repository represents an existing local Uniswap v4 project. Its intended economics are
documented in `docs/economics.md`. The source deliberately contains a concrete unbacked return-delta defect and an
unrestricted admin setter. The test suite covers fee direction but deliberately lacks an access-control regression.

This repository is public authored test data. It is not audited, approved, submitted, deployed, or live.
